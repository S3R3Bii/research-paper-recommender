# Paper recommendations that explain their limits

## Authorized scope and value

Study 41 is a working research-paper recommendation product and implementation exercise. A reader supplies a public paper title or known DOI, receives up to five related titles with matched-term explanations, or an explicit abstention. CLI, local HTTP API, browser UI, a learner stub, contract grader and runnable reference solution are required. No personal profiles, remote inference, paid service, private/formal manuscripts, abstracts or full text enter the product.

This scoped experiment supersedes the broader historical proposal of embeddings and human-audited supporting-evidence retrieval. It tests deposited citation recovery from title similarity. It cannot establish human relevance, citation correctness, study quality or support for a claim. No independent human relevance labels are available. No novelty, deployment, users, clinical advice or realized time saving is claimed.

## Source fixed before the corpus

Use eight Crossref /works requests with query.title values in this order: information retrieval; recommender systems; database query optimization; software defect prediction; graph neural networks; time series forecasting; machine translation; distributed consensus. Each request has rows=100, select=DOI,title,published,type,reference and filter=from-pub-date:2018-01-01,until-pub-date:2024-12-31,has-references:true. Keep response order and request hashes; no outcome-driven expansion or alternate query. A single earlier one-record schema preview is discovery only. Serial public unauthenticated requests, at least 1.1 seconds apart, honor returned limits and stop on 403/429. No bypass or key search.

Retain complete request responses privately. Publish only normalized DOI, first title, publication year, type, request stratum and distinct referenced DOI identifiers. Do not publish reference strings, authors, affiliations, ORCIDs, abstracts, funding, contact data or source papers. Crossref permits metadata reuse; abstracts can have separate copyright. Attribute Crossref and DOI links, with metadata errors and incomplete deposits explicitly possible. This is a current captured search snapshot, not a representative scholarly universe or historical release vintage. No DOI resolves to a full-text download.

For duplicate DOIs, the first request/record owns the query stratum and metadata; retain a duplicate audit and all unique reference DOI unions. Require nonempty cleaned title, valid DOI syntax and year 2018..2024, otherwise retain an exclusion. Clean tags/HTML entities, Unicode NFKC, normalize whitespace. Only journal-article and proceedings-article records are eligible. Keep other-type exclusions. Sort public records by DOI. Independently reconcile every selected value from the private originals before scoring.

## Unit, separation and coverage

Each unique paper is a potential query using only its own title. Candidate papers must have a strictly earlier publication year; the query DOI is never eligible. Labels are its deposited reference DOI intersection with those candidates. Queries with no such in-corpus references are excluded from scored citation-recovery metrics and retained in coverage output. Report the fraction of all potential queries with positive coverage, each stratum, reference counts and every exclusion. At least ten evaluable queries in each development/test partition are required; otherwise retain a coverage hold without changing the corpus. The first four request strata are development and the final four are held. Unique query DOIs cannot cross partitions. The candidate catalog may be shared; these are held query acquisition strata, not verified disjoint scientific topics. Current metadata is used retrospectively, with no prospective availability claim.

The ranker receives only DOI/title/year/type; reference labels and stratum never enter features. Per-query IDF is computed over eligible older candidate titles only. No citation-popularity feature, embedding or fitted probability. Titles are tokenized by NFKC/casefold, ASCII letters/digits of length >=2, excluding exactly: a an and are as at be by for from in is it of on or that the this to using via we with. This limited English-oriented tokenizer is an explicit limitation, with no stemming or language filtering.

## Fixed candidates and selection

Compare title-token-set Jaccard and log-TF/IDF cosine. For cosine, tf=1+ln(count); idf=1+ln((N+1)/(df+1)); L2 normalize query/document vectors; out-of-vocabulary query terms have zero weight. Explain cosine using per-term dot-product contributions and Jaccard using the intersecting tokens. Sort score descending then DOI ascending. Exclude score zero and matches with fewer than two distinct shared tokens. A query abstains when no candidate remains or its top score is below threshold. Otherwise return up to five eligible positive-match records, even when lower ranked scores are below the top-score threshold. This is a query-level abstention rule, not an item confidence threshold.

Search exactly 2 methods x 5 top-score thresholds [0,0.1,0.2,0.3,0.4]. Primary selection is equal-query mean proxy utility: +1 for an answered query with any deposited reference in top five; -0.25 for an answered query with no deposited reference; 0 for abstention. The penalty is a declared hypothetical teaching tradeoff, not measured human cost. Ties prefer lower threshold, then Jaccard. Report every candidate and stratum. Fixed baseline is Jaccard threshold zero. A finite grid and a boundary winner do not establish optimality or calibrated confidence.

Report answered coverage, proxy hit@5 over all evaluable queries, hit@5 among answered, deposited-reference recall@5 (sum hits / each query positive count, then macro mean), reciprocal rank of the first deposited reference (zero when absent), proxy utility and all stratum results. Unlisted recommendations are unjudged, not proven false positives. Do not call these human precision, safety or claim-support metrics. Retain every query, ranked DOI, score, matched terms and deposited-reference indicator. No statistical significance or population generalization claim; this finite snapshot is descriptive. All held query outcomes are computed only after committing the development selection and hashes of source/design/code dependencies.

## Fixed robustness and unknowns

After freezing, evaluate the selected rule and baseline on held queries. Also retain all eight synthetic unrelated queries: sourdough starter feeding schedule; bicycle tire puncture repair; indoor orchid watering tips; watercolor landscape brush technique; packing suitcase beach holiday; sour cherry jam recipe; acoustic guitar string replacement; puppy house training schedule. These are authored negative controls, not independent user relevance labels or evidence of general out-of-domain safety. Assess known DOI exclusion and empty/no-vocabulary inputs with hand fixtures. No threshold retuning from these controls or test outcomes. Human usefulness, support verification, multilingual retrieval and general out-of-domain detection remain unknown.

## Acceptance and bounded independent checks

Pass requires source/rights reconciliation, disjoint query IDs and correct older-candidate lineage, all ten candidate results, frozen selection before held scoring, independent metric/ranking reconstruction, meaningful exercise/reference/API boundary tests, isolated offline replay, source-backed figures, readable responsive UI inspected in a browser, and all final manuscript pages rendered and inspected. Correctness/privacy gates cannot be averaged away. UI appearance does not establish accessibility conformance. Record finite checks and limitations; grade 4 means the scoped criteria pass, not universal quality. Keep previous failures. At most three substantive review rounds, 45 active review minutes and 60 review-specific calls, excluding execution and remote release operations. Separate formal-publication projects remain private.
