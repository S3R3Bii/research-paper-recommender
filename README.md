# Research paper recommender

An explainable recommendation engine and implementation exercise for finding related research titles. The product will run locally with a CLI, API and browser interface. Recommendations will be title matches, not verified evidence for a claim.

**Current state: protocol committed before corpus collection; product and evaluation incomplete.**

Read [the fixed protocol](PROTOCOL.md) and [source boundaries](DATA_RIGHTS.md). Study 41 narrows the historical evidence-retrieval proposal to an honest, runnable recommendation exercise. Separate formal-publication projects are excluded.
